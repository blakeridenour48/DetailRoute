Back up your data

Pins are saved in this browser on this phone, NOT synced to other devices. Export a backup often, especially before changing phones or clearing Safari data.

Restoring a backup replaces all existing pins on this phone.

Install on iPhone

After hosting this app on HTTPS, open it in Safari, tap Share → Add to Home Screen. It will appear like an app.

Google Maps requires an internet connection. Your stored records remain on this device but the map will not load offline.

🗺️ Connect Google Maps

Your house pins and sales tracker are ready. To show the Google map, add your Google Maps JavaScript API key.

Create a key in Google Cloud Console. Enable Maps JavaScript API, attach billing, and restrict the key by website domain. Google may charge for usage beyond free usage limits.

You can explore the Houses, Dashboard and Settings tabs without a map, but map-based pin placement needs the key.
